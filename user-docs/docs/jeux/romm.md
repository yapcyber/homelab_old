# RomM — jeux rétro

## À quoi ça sert

RomM est une **bibliothèque de jeux rétro** (ROMs) avec de belles jaquettes, qui
permet aussi de **jouer directement dans le navigateur** (émulation intégrée).

## Comment l'utiliser

1. Adresse : **romm.yapserver.fr** (VPN activé + connexion).
2. Parcours les consoles, choisis un jeu, clique pour jouer en ligne.

## Bon à savoir

- Certaines consoles nécessitent des **fichiers BIOS** pour fonctionner — si un
  jeu ne se lance pas, c'est souvent ça (demande à Yanis).
- Utilise uniquement des jeux que tu possèdes légalement.

*(À ne pas confondre avec [Kyber](../cloud-gaming/kyber.md), qui sert à jouer à
des jeux PC modernes en streaming.)*
