# Jellystat — statistiques Jellyfin

## À quoi ça sert

Jellystat affiche des **statistiques d'utilisation de Jellyfin** : ce qui est le
plus regardé, l'activité récente, l'espace occupé par la bibliothèque, etc.

## Comment l'utiliser

- Adresse : **jellystat.yapserver.fr** (VPN + connexion).
- Purement informatif : on y consulte des graphiques, on ne lit pas les médias
  ici (ça, c'est [Jellyfin](./jellyfin.md)).

## Bon à savoir

Outil surtout utile à l'administrateur pour suivre l'usage de la médiathèque.
