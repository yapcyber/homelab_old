# Stirling PDF — boîte à outils PDF

## À quoi ça sert

Stirling PDF regroupe des dizaines d'**outils PDF** : fusionner, découper,
compresser, convertir (Word/images ↔ PDF), pivoter, ajouter un mot de passe,
signer, faire de la reconnaissance de texte (OCR)…

## Comment l'utiliser

- Adresse : **pdf.yapserver.fr** (VPN + connexion).
- Choisis l'outil voulu, dépose ton fichier, récupère le résultat.

## Bon à savoir

Tout est traité **localement** : tes documents ne quittent jamais la maison —
pratique pour des papiers sensibles.
