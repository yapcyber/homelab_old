# Modèle — [sujet]

> Dupliquer cette page pour chaque sujet d'interrogatoire. Trame :
> **situation réelle → rôle exact → action personnelle → résultat → trace disponible.**

## Situation

Contexte réel, factuel (où, quand, quel périmètre).

## Rôle exact

Ce que **tu** as fait précisément (sans t'attribuer plus que ton rôle réel).

## Action personnelle

Les étapes concrètes que tu as menées.

## Résultat

Ce qui a changé / été produit, si possible mesurable.

## Trace disponible

Lien vers la preuve (capture, extrait, commit, document). Si oral uniquement,
l'indiquer explicitement.
