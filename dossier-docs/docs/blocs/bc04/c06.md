# BC04 · C6 — Outils collaboratifs

**Statut : Solide.**

## Intitulé

**Intitulé (abrégé du référentiel).** Utiliser les outils collaboratifs de transmission des savoirs.

**Critère d'évaluation.** Le travail en équipe est efficace.

## Interprétation

Montrer des outils collaboratifs réellement utilisés pour transmettre, pas simplement installés.

## Réponse

Chez Dupont : base de connaissances d'équipe, Kanban du projet
périphériques, SharePoint (dépôt du rapport PingCastle partagé avec le SOC,
flux PowerAutomate). Sur le homelab : le **dépôt Git comme source de vérité**
(tout part du poste de contrôle) et les **Docusaurus** comme supports de
transmission (documentation utilisateurs et portfolio).

## Preuves et chemin de raisonnement

- Captures anonymisées (Kanban, espace partagé).
- Dépôt Git et sites de documentation en démonstration.
