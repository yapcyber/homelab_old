# BC02 · C9 — Migrer une architecture

**Statut : À confirmer — journaux à extraire.**

## Intitulé

**Énoncé du référentiel.** Migrer une architecture vers une cible nouvelle en maîtrisant les risques et en validant le succès.

**Critère d'évaluation.** L'architecture cible est mise en place avec traçabilité des contrôles et des précautions.

## Interprétation

Montrer une migration réelle avec **méthode** : contrôles avant et après, précautions prises (sauvegarde, fenêtre, migration à froid), et lucidité sur les échecs et les leçons.

## Réponse

**Origine de l'acquisition.** J'ai réalisé plusieurs migrations réelles sur Proxmox, avec succès et échecs.

**Contexte.** (1) **Migration d'urgence pour résoudre la surallocation** (incident de C7) : VM NetBox surchargée (12 Go RAM sur pve1 surchargé) → migration à chaud vers pve2 (7 min d'interruption minimale). Méthode : snapshot pré-migration, changement de nœud dans Proxmox, vérification post (ping, logs conteneur). (2) **Délestage planifié** : Jellyfin et NetBox sur pve1 → migration à froid vers pve3 (45 min total, 3 min d'arrêt applicatif). (3) **Pré-staging du modèle Debian 13** : contrainte architecturale (interdiction clone inter-nœud sur stockage local). Solution : créer le clone sur pve3, puis promouvoir en template.

J'assume aussi un **échec instructif** : la **migration fantôme** (migration lancée sous un délai de reconnexion trop court, le processus distant survit). Leçon appliquée : toujours vérifier l'état du processus distant après timeout réseau.

Précautions systématiques : snapshot/sauvegarde pré-migration, migration à froid pour stockage local, vérification du nœud cible (espace libre, charge, RAM). Côté entreprise : la transition WSUS → Tanium (non réalisée encore, plan futur).

## Preuves

- Journaux de migration Proxmox (qm log).
- Snapshot horodaté pré-migration.
- Procédure de migration à froid (étapes documentées).
- Notes d'apprentissage de la migration fantôme (diagnostic, solution appliquée).
- Capture Proxmox Dashboard avant/après (charge rééquilibrée).
- Éléments anonymisés sur la transition WSUS/Tanium.
