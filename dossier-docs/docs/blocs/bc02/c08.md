# BC02 · C8 — Recenser et cartographier le SI

**Statut : Solide — NetBox à actualiser.**

## Intitulé

**Intitulé (abrégé du référentiel).** Recenser les ressources et maintenir la cartographie du SI.

**Critère d'évaluation.** La cartographie du SI permet l'intégration maîtrisée de nouveautés.

## Interprétation

La cartographie doit servir : montrer qu'un ajout récent s'y intègre de façon maîtrisée (choix du VLAN, de l'adresse, des dépendances et des règles de filtrage), pas seulement qu'un inventaire existe.

## Réponse

**Cartographie porte : NetBox.** L'outil centralise l'inventaire réseau : machines physiques (trois Protectli, commutateur, pare-feu), VM (neuf services), VLAN (10 segments), adresses IP et associations de services. La cartographie est la **source de vérité** : tout ajout ou modification passe par NetBox avant déploiement.

**Démonstration : intégration de la VM portfolio en DMZ.** Contexte : le site Web du dossier de validation devait être exposé de façon limitée (lecture seule, derrière Authentik). Processus suivi :
1. **Planification NetBox** : création du VLAN 40 (DMZ), réservation d'une IP (10.0.40.100), définition du service « portfolio ».
2. **Règles de filtrage** : configuration OPNsense -> DMZ peut recevoir HTTP/HTTPS depuis Internet, DNI (demandes non initiées) bloquées, pas de chemin DMZ->Prod.
3. **Déploiement** : déploiement de la VM, jointure au VLAN 40, relai du tunnel DNS vers Unbound.
4. **Vérification** : test d'accessibilité depuis le Internet (VPN), test que DMZ n'accède pas à Prod (iperf3 blocked).

**Analogie entreprise.** Chez Dupont, Tanium/GLPI joue le même rôle pour l'inventaire des postes et logiciels ; LogMeIn ou RDPGateway pour l'accès documenté.

## Preuves et chemin de raisonnement

- **Capture NetBox avant/après** : écrans côte-à-côte montrant (a) état avant intégration portfolio (VLAN 10-30-50-60-70-80-90-100), et (b) après ajout VLAN 40 + portfolio service.
- **Fiche NetBox de la VM portfolio** : nom, VLAN 40, IP 10.0.40.100, services hébergés (Docusaurus + Authentik), interfaces réseau.
- **Schéma logique versionné** : diagramme Lucidchart ou PlantUML en Git, montrant avant/après, avec zones colorées (Prod vert, DMZ rouge, DMZ isolée).
- **Historique Git** : commit d'ajout du VLAN 40 + ticket ou PR d'intégration.
- **Capture OPNsense** : règles DMZ -> Internet (allow HTTP/S), DMZ -> LAN (deny), LAN -> DMZ (allow reply).
- **Test d'isolation** : résultat iperf3 DMZ -> Prod (bloqué), DMZ -> Internet (140 Mbps).
- **Capture anonymisée Tanium ou GLPI** (si autorisée par Dupont) : écran inventaire postes avec compteur de machines par type.
