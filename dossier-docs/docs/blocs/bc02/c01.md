# BC02 · C1 — Gérer les évolutions (ITSM)

**Statut : **Validée.** Le texte final est à récupérer dans les sources.**

## Intitulé

**Intitulé (abrégé du référentiel).** Gérer les évolutions selon les principes de l'IT Service Management.

**Critère d'évaluation.** Compétence déclarée validée (critère couvert par le texte validé).

## Interprétation

Identifier, qualifier et prioriser les demandes d'évolution avec une démarche alignée ITSM, et montrer comment les constats sont transmis aux bonnes instances.

## Réponse

Mon positionnement exact est celui d'un **contributeur** : je dépose le rapport
mensuel PingCastle, je fournis des constats au COSECOPS et je challenge le SOC.
Je ne me présente jamais comme responsable ou animateur du COSECOPS. Le projet
de restriction des périphériques illustre une amélioration **progressive**
(recensement, test restreint, affinement, généralisation) plutôt qu'un
changement brutal. Le cours ITIL suivi à Ynov (18/20) est présenté comme une
**formation, pas une certification**.

## Preuves et chemin de raisonnement

- Tableau de bord CVE utilisé dans le cadre du COSECOPS (anonymisé).
- Rapport mensuel PingCastle ou page de synthèse (anonymisé).
- Trace du dépôt du rapport dans l'espace partagé avec le SOC.
- Chronologie du projet de restriction des périphériques.
- Résultat du cours ITIL Ynov, présenté comme formation.
