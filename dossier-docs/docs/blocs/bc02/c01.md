# BC02 · C1 — Gérer les évolutions (ITSM)

**Statut : Validée.** Le texte final est à récupérer dans les sources.

## Intitulé

**Énoncé du référentiel.** Gérer les évolutions du Système d'Information selon les principes de l'IT Service Management : identifier, qualifier et prioriser les demandes d'évolution avec une démarche alignée ITSM.

**Critère d'évaluation.** Les évolutions du SI sont gérées selon une démarche ITSM structurée.

## Interprétation

Le critère exige une **démarche ITSM réelle**, pas juste une description d'outils : montrer comment les demandes d'évolution sont identifiées, qualifiées, priorisées, et transmises aux décideurs.

## Réponse

**Origine de l'acquisition.** J'ai acquis cette compétence chez Dupont Restauration où j'interviens dans le pilotage des évolutions sécurité auprès du COSECOPS.

**Contexte.** Mon rôle exact est celui d'un **contributeur**, jamais de responsable. Je dépose les rapports mensuels PingCastle qui alimentent les constats, je fournis des recommandations au COSECOPS, et je challenge les propositions du SOC sur leur pertinence technique. Le projet de restriction des périphériques illustre la démarche ITSM : une amélioration progressive (demande, test restreint, affinement, commande, déploiement par rings) plutôt qu'un changement brutal. Le cours ITIL suivi à Ynov (18/20) est présenté comme une **formation**, pas une certification.
