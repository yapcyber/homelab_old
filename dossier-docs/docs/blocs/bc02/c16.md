# BC02 · C16 — Indicateurs environnementaux

**Statut : Trace à créer — tableau à consolider.**

## Intitulé

**Intitulé (abrégé du référentiel).** Définir des indicateurs RSE et environnementaux.

**Critère d'évaluation.** Des indicateurs environnementaux sont définis.

## Interprétation

Des indicateurs simples, reproductibles chaque mois, qui permettent réellement une décision — en évitant qu'un ratio de consolidation élevé masque une surallocation.

## Réponse

**Trois indicateurs RSE/environnementaux définis et mesurables.**

| Indicateur | Formule | Fréquence | Valeur initiale | Cible | Source | Limites |
|---|---|---|---|---|---|---|
| Consommation énergétique (kWh/mois) | Watt moyen * heures / 1000 | Mensuel | environ 58 kWh (Watt moyen 200 W, 24h*30j) | < 50 kWh | Wattmètre (a acquerir) ou estimation amperemetre | Wattmetre non acquis ; estimation +-10 % |
| Ratio de consolidation | Services heberges / Machines physiques | Trimestriel | 3.7 (11 services / 3 machines) | >= 3.5 | Inventaire Git + docker ps | Augmentation du ratio necessite marge RAM |
| Part du remploi (%) | Machines/composants d'occasion / Total equipement * 100 | Annuel | 95% (Protectli + Cisco + cartes Mellanox) | >= 90% | Inventaire d'acquisition + factures | Neufs limites a SSD (necessaires) |

**Définitions détaillées.**

**Consommation énergétique.** Mesure : ampérométrie sur l'alimentation du cluster (environ200 W en charge, environ30 W idle). Fréquence : relevé hebdo via la facture électrique (kWh cumulés) ou Prometheus si sonde disponible. Objectif : < 50 kWh/mois (gain de 10 kWh vs. 2025 via extinction Security Onion).

**Ratio consolidation.** Dénominateur : nombre de machines physiques hébergées (3 Protectli). Numérateur : services applicatifs distincts en production (Jellyfin, Nextcloud, OpenWrt, OPNsense, Wazuh, NetBox, etc.). Calcul : 11 services / 3 machines = 3.7. Limite : augmenter le ratio au-delà de 4 risque une surallocation RAM.

**Part réemploi.** Acquisition de chaque équipement documentée : [neuf | occasion | don]. Calcul : (occasion + don) / total. Cible : maintenir ≥ 90 % pour minimiser l'empreinte fabrication. Excepté : disques SSD (pas d'offre occasion viable à perf suffisante).

## Preuves et chemin de raisonnement

- **Tableau récapitulatif** : reprenant le tableau ci-dessus avec valeurs réelles mesurées.
- **Historique mensuel de consommation** : (à créer) colonnes [Mois | Consommation (kWh) | Moyenne glissante 3 mois | Notes (ex. Security Onion arrêtée en juillet)].
- **Inventaire du matériel** : CSV ou tableau avec [Élément | Date achat | Neuf/Occasion | Coût | Fournisseur].
- **Graphique évolution ratio consolidation** : axe Y = ratio, axe X = mois ; affiche progression ou stagnation.
- **Calcul CO₂** : (kWh consommés) * 0.07 kg CO₂/kWh (facteur France 2025) = kg CO₂ équivalent.
- **Comparaison année N vs. N-1** : si disponible, tableau montrant les variations et causes (ex. « Mois 7 : baisse 10 % -> extinction Security Onion »).
