# BC03 · C14 — Éléments critiques de continuité

**Statut : À confirmer — s'appuie sur la BIA.**

## Intitulé

**Intitulé (abrégé du référentiel).** Identifier les éléments critiques pour la continuité d'activité.

**Critère d'évaluation.** Les rôles critiques et les ressources indispensables sont identifiés.

## Interprétation

Identifier ce qui est réellement indispensable et le documenter : dépendances, points de défaillance uniques, points de contrôle quotidiens.

## Réponse

Sur le homelab, la BIA identifie les ressources indispensables et leurs
dépendances, dont le **point de défaillance unique documenté** : la VM TrueNAS
sur pont USB, qui porte le stockage partagé (la HA protège d'une perte de nœud
de calcul, pas du stockage). Chez Dupont, le **journal d'exploitation**
(vingtaine de points vérifiés chaque matin, conditionnant le démarrage de la
production) est une identification réelle des éléments critiques, dont je tiens
le volet sécurité.

## Preuves et chemin de raisonnement

- Tableau BIA (partagé avec C11).
- Grandes catégories du journal d'exploitation (Dupont, anonymisé, sans détail
  sensible).
