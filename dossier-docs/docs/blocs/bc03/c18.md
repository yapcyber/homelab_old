# BC03 · C18 — Sécurité cohérente sur site et dans le Cloud

**Statut : À confirmer — politique cloud à formaliser (1 page).**

## Intitulé

**Énoncé du référentiel.** Assurer un modèle de sécurité cohérent entre l'infrastructure sur site et les services Cloud (données, identités, chiffrement, logs).

**Critère d'évaluation.** Une politique de sécurité Cloud est définie, documentée et implémentée : ce qui va au cloud, ce qui reste interne, conditions et responsabilités.

## Interprétation

Politique définie = choix explicite, formalisé par écrit. Ne pas affirmer « on fait du cloud » ; documenter « Cloudflare héberge le DNS car [raison], les backups sont chiffrés avant envoi car [raison], tout reste VPN sauf [exception] ».

## Réponse

**Origine de l'acquisition.** J'ai défini la politique cloud du homelab et contribué à l'audit cloud chez Dupont.

**Contexte.** Politique cloud personnelle (en pratique, formalisée en 1 page) : (1) **Données au cloud** : DNS public via Cloudflare (DDoS protection, haute disponibilité, conforme car données non-sensibles). (2) **Exposition portfolio** : tunnel Cloudflare sortant (no inbound ports), déploiement du portfolio depuis CI/CD vers Netlify chiffré en transit (TLS 1.3). (3) **Backups au cloud** : restic vers Drive Google, **chiffrés côté client** avant envoi (AES via restic, mot de passe separate de données) — fournisseur cloud ne voit que du blob chiffré. (4) **Identités** : Authentik interne VPN-only, pas de fédération cloud (risque trop élevé pour données sensibles). (5) **Conditions** : secrets chiffrés par SOPS/Age, MFA chez fournisseurs cloud (Cloudflare, Google), audit trimestriel des accès cloud.

Chez Dupont : politique cloud connue (SharePoint Online, Teams avec MFA + DLP Microsoft) et précautions personnelles : exports sensibles (paie, RH) téléchargés localement avant suppression du cloud, jamais stockage permanent cloud-side.

## Preuves

- Politique cloud homelab rédigée (1-2 pages) : ce qui va au cloud, pourquoi, conditions, responsabilités.
- Configuration restic (chiffrement côté client, algorithme, clé séparée).
- Configuration Cloudflare (tunnel, TLS version, logs).
- Configuration SOPS/Age (chiffrement des secrets versionnés).
- Politique MFA fournisseurs cloud (captures d'config ou attestation).
