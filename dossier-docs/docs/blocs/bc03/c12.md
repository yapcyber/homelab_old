# BC03 · C12 — Chiffrer les canaux de sauvegarde

**Statut : Solide — 3-2-1-1-0 en production, restaurations testées.**

## Intitulé

**Énoncé du référentiel.** Chiffrer les données de sauvegarde au repos et en transit, formaliser la gestion des archives et des clés.

**Critère d'évaluation.** Les tests de sauvegarde et restauration sécurisée sont validés ; les clés de chiffrement sont gérées et protégées.

## Interprétation

Montrer le **cycle complet** : données chiffrées au repos (algorithme, clés séparées des données), en transit (TLS/SSH), et au stockage (offline ou géolocalisation). Preuve par restauration réussie, pas juste « config en place ».

## Réponse

**Origine de l'acquisition.** J'ai conçu et maintenu la chaîne de sauvegarde 3-2-1-1-0 du homelab en production.

**Contexte.** Stratégie **3-2-1-1-0 en production** : (1) **Trois sauvegardes** : dumps quotidiens locaux + restic hors site (chiffré côté client) + clé USB offline. (2) **Deux médias** : stockage en ligne (Drive Google) + clé USB LUKS. (3) **Deux emplacements** : site local (homelab) + site distant (cloud + USB chez tiers). (4) **Un objectif de vérification** : test restauration tous les mois. (5) **Zero manual key storage** : clés dans Vaultwarden (seed backing du mot de passe maître).

Détails : dumps quotidiens chiffrés localement (OpenSSL AES-256-CBC, PBKDF2), vérification d'intégrité daily (sha256sum) avec alerte ntfy. Restic : chiffrement client-side avant envoi vers Drive (passphrase différente des clés locales), rétention granulaire (7j/4s/3m). USB LUKS : branchement une fois/semaine pour copie des archives, clé physiquement isolée après.

Restauration testée : (1) 22 juillet 2024 : restore Nextcloud depuis backup hors site (réussi, 1h30), (2) USB LUKS : restore PostgreSQL depuis backup USB (réussi, 45 min). Logs de restauration conservés.

## Preuves

- Configuration sauvegarde (dump + restic + USB) anonymisée / expurgée.
- Journal d'une exécution de sauvegarde : dump, intégrité check, restic sync, résultat.
- Configuration restic (profils hôte, rétention, algorithme).
- Procédure restauration (étapes, outils, durée estimée).
- Logs restauration du 22 juillet (anonymisés, preuve de succès).
- Photo USB LUKS chiffrée (visuel, avec manifeste écrit sur étiquette).
