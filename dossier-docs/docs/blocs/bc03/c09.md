# BC03 · C9 — Évaluer les perturbations via les sondes

**Statut : Solide — coverage réseau + hôte, angles morts documentés.**

## Intitulé

**Énoncé du référentiel.** Évaluer les perturbations et anomalies via les sondes de détection (IDS/IPS, SIEM, EDR).

**Critère d'évaluation.** Une évaluation des risques liés aux malveillances est produite, avec couverture des sondes et angles morts documentés.

## Interprétation

Ne pas affirmer « les sondes détectent tout ». Montrer que chaque sonde a une portée limitée, et comment elles se complètent. Prouver la compréhension des angles morts.

## Réponse

**Origine de l'acquisition.** J'ai qualifié des détections réseau et hôte sur le homelab et traité des alertes SOC chez Dupont.

**Contexte.** Sur le homelab, deux sondes : **Wazuh** (détection hôte) sur 8 agents, **Security Onion** (Suricata réseau) sur l'interface d'accès au réseau. J'ai investigué une **détection est-ouest** : trafic anormal entre deux VMs vu par Suricata (réseau) mais absent des logs Wazuh. Leçon : Wazuh détecte les anomalies aux niveaux application et système (logs, processus), pas le trafic en transit entre postes. Suricata détecte le trafic réseau. Donc : une compromission qui lance un beaconing chiffré qui échappe à Wazuh est visible à Suricata. Couverture complète exige les deux.

Chez Dupont, j'ai qualifié des alertes EDR et SOC (Trend Micro, équipe SOC interne). Exemple : signature de malveillance détectée sur un poste → EDR enregistre le PID et le chemin → je localise le fichier source (USB externe, email, partage réseau), isole le poste, nettoie, vérifiée post-scan EDR. Post-mortem écrit : quand, d'où, comment détecté, actions, récurrence à prévenir.

## Preuves

- Configuration Wazuh : agents actifs, règles appliquées (ex. sysmon pour détection comportement).
- Configuration Suricata : règles appliquées, interface surveillée.
- Exemple de détection Wazuh anonymisée (alerte, logs sources, investigation).
- Exemple de détection Suricata anonymisée (flux, signature, classification).
- Analyse : angles morts de chaque sonde et comment elle couvre l'autre.
- Extrait post-mortem SOC (Dupont, anonymisé).
