# BC03 · C3 — Configurer des solutions de sécurité classiques

**Statut : Solide — OPNsense, DNS unbound, firewall applicatif.**

## Intitulé

**Énoncé du référentiel.** Configurer et maintenir des solutions de sécurité classiques du Système d'information : pare-feu, IDS/IPS, DNS de sécurité, filtrage, appliances.

**Critère d'évaluation.** Les configurations des services réseaux (pare-feu, DNS, proxy, IDS/IPS) sont conformes aux bonnes pratiques et documentées.

## Interprétation

Montrer une **configuration concrète** — pas juste « mettre en place », mais « chiffrer pourquoi ce paramètre, et le prouver avec une capture ». Chaque service a une raison : refus par défaut, isolation, logging.

## Réponse

**Origine de l'acquisition.** J'ai configuré et maintenu le pare-feu OPNsense du homelab, DNS unbound, et VPN SSO chez Dupont.

**Contexte.** Homelab : **OPNsense** (pfSense fork) configure les règles par VLAN avec une politique **refus par défaut**, d'où quelques acceptations explicites pour chaque flux. Isolation prouvée entre DMZ (VLAN 40, portfolio VM) et production (VLAN 10, services critiques) : iperf3 test confirme aucun flux croisé. **DNS unbound** configuré pour résolution locale + blocage de domaines nuisibles (listes Tao, pfBlocker). **Authentik** en SSO forward-auth (Traefik middleware) avec enrôlement TOTP, groupes, et blueprints de provenance (OIDC, LDAP). VPN OpenVPN + Authentik chez Dupont avec MFA TOTP obligatoire, policy de certificat client ou LDAP.

Firewall applicatif : règles d'accès aux bases de données (MySQL socket local seulement), API backend sur reverse proxy avec authentification JWT, pas de flux brut vers les bases depuis les postes.

## Preuves

- Configuration OPNsense anonymisée (politique refus par défaut, exemple de règles DMZ, production).
- Capture isolation DMZ/production (iperf3 test, logs de rejet).
- Configuration DNS unbound (listes de blocage, fichiers hosts locaux).
- Blueprints Authentik (provenance, enrôlement, MFA).
- Configuration VPN OpenVPN (certificat client, MFA, profil utilisateur).
