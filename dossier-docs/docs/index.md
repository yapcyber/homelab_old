# Dossier de validation — YapServer

Espace de travail privé (VPN-only) pour constituer le dossier : **récolter les
preuves**, **rédiger les interrogatoires** et **suivre l'avancement**. Le rendu
final sera au format Word, mais tout se prépare et se centralise ici.

## Organisation

| Section | Contenu |
|---|---|
| **Preuves** | Suivi des preuves (statut par item) + preuves rassemblées, classées par bloc de compétences. |
| **Interrogatoires** | Une page par sujet d'interrogatoire (situation, rôle, action, résultat, trace). |
| **Résultat** | Synthèse et résultat du dossier. |

## Comment l'utiliser

- Une page Markdown = un sujet (preuve, interrogatoire, note).
- Ranger les fichiers dans `docs/<section>/` ; le sommaire se génère tout seul.
- Coller captures / extraits dans `static/img/` et les référencer.
- Rien n'est public : le site est **VPN-only** (`dossier.yapserver.fr`).

> Point de départ : la page **[Suivi des preuves](/preuves/suivi)**.
